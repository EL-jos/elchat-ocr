Activer et tester le widget

Deux activations distinctes

Section intitulée « Deux activations distinctes »

Dans les paramètres du site :

  • Widget activé contrôle l’affichage de l’interface ;
  • IA activée contrôle la production des réponses IA.

Vérifiez les deux réglages pour un parcours conversationnel standard.

Test avant ouverture au public

Section intitulée « Test avant ouverture au public »
  1. Utilisez Test Connection pour détecter l’installation.
  2. Ouvrez le site public dans une nouvelle fenêtre.
  3. Vérifiez la position et le texte du bouton.
  4. Ouvrez le widget.
  5. Posez une question couverte par les connaissances.
  6. Testez une reformulation.
  7. Posez une question non couverte et observez le message de repli.
  8. Retrouvez la conversation dans le dashboard.

Critères de réussite

Section intitulée « Critères de réussite »
  • le bouton apparaît ;
  • le widget s’ouvre ;
  • le message d’accueil est correct ;
  • un message peut être envoyé ;
  • une réponse est reçue ;
  • la conversation apparaît dans l’onglet Conversations ;
  • les contenus proposés ouvrent la bonne destination.

Désactiver temporairement

Section intitulée « Désactiver temporairement »

Désactivez le widget lorsque vous ne souhaitez plus l’afficher. Désactivez uniquement l’IA si vous devez maintenir l’interface mais empêcher les réponses automatiques selon le comportement prévu par votre exploitation.

Testez le comportement exact

La vue Conversations du site reste en lecture seule pour l’administrateur. Ne désactivez pas l’IA en supposant qu’un opérateur pourra répondre depuis cet écran.

Exemple de recette de test

Section intitulée « Exemple de recette de test »

Pour un site e-commerce, utilisez ce petit scénario :

  1. envoyez « Quels sont vos délais de livraison ? » et vérifiez la réponse issue des connaissances ;
  2. reformulez la question pour contrôler la stabilité ;
  3. demandez une information absente et vérifiez le message de repli ;
  4. déclenchez le CTA de demande de devis et contrôlez sa destination ;
  5. retrouvez la conversation dans Conversations.

Ces tests isolent les trois éléments qui peuvent échouer : l’affichage du widget, la réponse IA et le lien vers une action configurée. Notez le résultat attendu avant le test afin de repérer précisément le réglage à corriger.
