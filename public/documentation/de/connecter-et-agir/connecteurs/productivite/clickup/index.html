Connect Clickup

Wozu ist diese Verbindung?

ClickUp ermöglicht es ELChat, Leerzeichen und Listen zu durchsuchen, Aufgaben anzuzeigen, Status zu erstellen, zu ändern und Kommentare hinzuzufügen.

Was sie brauchen

ELChat erfordert einen ** persönlichen API-Token** ClickUp. Dieses Token repräsentiert Ihren Benutzer und erbt seine Rechte. Fiktives Beispiel: pk_xxxxxxxxxxxxxxxxxxxxx.

Die offizielle Dokumentation ClickUp behält den persönlichen Token für den persönlichen / internen Gebrauch vor; OAuth wird für eine Anwendung empfohlen, die von mehreren Konten verwendet wird.] ELChat implementiert den persönlichen Token hier.

Holen Sie sich das token

Abschnitt betitelt „Holen Sie sich das token“
  1. Melden Sie sich bei ClickUp mit dem Konto an, das auf die gewünschten Workspaces. 2 zugreift. Öffnen Sie Ihre Persönlichen Anpassungen.
  2. Gehen Sie zu Apps.
  3. Klicken Sie in API Token auf Generate oder kopieren Sie den vorhandenen token.
  4. Bewahren Sie es als Passwort auf.

Login und check

Abschnitt betitelt „Login und check“
  1. Öffnen Sie Dashboard > Ihre Website > KI-Aktionen > Connectors.
  2. Klicken Sie auf Connect auf der Karte ClickUp.
  3. Fügen Sie den persönlichen API-Token und validate.
  4. Bitten Sie ELChat, barrierefreie Workspaces. 5 aufzulisten. Wählen Sie dann ein Leerzeichen oder einen Ordner, listen Sie dessen Listen auf und überprüfen Sie dann eine bekannte task.

ELChat fordert keine aID im Formular an: Er entdeckt zuerst die Workspaces, verwendet dann die IDs der Leerzeichen, Ordner, Listen und Aufgaben, die von ClickUp zurückgegeben werden.

Verfügbare Kapazitäten

Abschnitt betitelt „Verfügbare Kapazitäten“

Verfügbare Kapazitäten

Abschnitt betitelt „Verfügbare Kapazitäten“

Listen Sie die Aufgaben einer Liste auf, mit dem Statusfilter Sehen Sie die Details einer Aufgabe Erstellen einer Aufgabe in einer Liste Ändern Sie den Status einer Aufgabe Hinzufügen eines Kommentars

Generieren Sie ein neues Token, verbinden Sie es erneut, testen Sie die Arbeitsbereiche **Listen ** und widerrufen Sie dann den alten. Die CLChat-Deaktivierung entwertet das Token in ClickUp.

  • Kein Arbeitsbereich: Der Token-Besitzer gehört keinem zugänglichen Arbeitsbereich an.
  • Liste nicht gefunden: Überprüfen Sie den ausgewählten Platz oder Ordner.
  • Statute refused: Der Name muss genau einem in der Liste konfigurierten Status entsprechen.
  • Fehler 429: warten auf Reset; ClickUp-Limits variieren je nach Paket.

Security

Abschnitt betitelt „Security“

Das persönliche Token kann alles beeinflussen, was der Benutzer sieht. Verwenden Sie ein dediziertes Konto oder reduzieren Sie den Zugriff auf die erforderlichen Arbeitsbereiche.

Beispiel: Klicken Sie auf ein team

Verbinden Sie einen dedizierten Benutzer, der nur zum Arbeitsbereich Maison Atlas — Support gehört, und fordern Sie dann die Liste der Arbeitsbereiche an. Wählen Sie das Leerzeichen und die von ClickUp zurückgegebene Liste und testen Sie die Wiedergabe einer bekannten Aufgabe, bevor Sie eine Aufgabe erstellen oder ändern.

ClickUp entdeckt die IDs nach dem Anmelden: Erfinden Sie sie nicht im Formular. Das Lesen bestätigt die Rechte für Arbeitsbereich, Speicherplatz, Liste und Token; die Einträge müssen erst nach dieser Prüfung aktiviert werden.
