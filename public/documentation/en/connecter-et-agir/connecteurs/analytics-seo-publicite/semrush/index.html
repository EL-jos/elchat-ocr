Connect Semrush

What is this connection for?

Section titled “What is this connection for?”

Semrush allows ELChat to obtain competitive SEO data: domain visibility, organic keywords, keyword potential, backlinks, competitors and opportunities.

What you need

Section titled “What you need”
Identifier Role Fictitious example
Semrush API key Authenticate and bill API units semrush_xxxxxxxxxxxxxxxxxxxxx
Default domain Avoid repeating the analyzed domain exemple.com
Geographical basis Select the regional base fr, us, uk

Standard API requires API access and available units. Semrush currently indicates that the standard API is linked to Business SEO Toolkit and to the purchase of API units; check your subscription as these offers may evolve.

Get API key

Section titled “Get API key”
  1. Log in to Semrush.
  2. Open your profile.
  3. Go to My profile > API Keys. On some interfaces, the information can still appear under Subscription Info > API Units.
  4. Create or display the available key.
  5. Copy it without space.

See the [official API key guide]](#)and the rapid start of the Semrush API.

Connect Semrush to ELChat

Section titled “Connect Semrush to ELChat”
  1. Open Dashboard > your site > IA Actions > Connectors.
  2. Click Connect on the Semrush map.
  3. Paste the API key.
  4. Enter the domain without protocol or path.
  5. Enter the desired geographic base, for examplefr.
  6. Validate.

Check connection

Section titled “Check connection”

Ask for an overview of the default domain and compare the main indicators in Semrush with the same geographical base.

Capacity available

Section titled “Capacity available”
Actual capacity Type
Overview of a domain Reading

Overview of a keyword Reading
Summary of backlinks of a domain Reading
Organic competitors, default 10 and maximum 50 Reading
Suggestions for opportunities, with starting keyword or competing domain Reading

ELChat does not modify any Semrush projects and does not create a SEO campaign.

Reconnect, Disconnect and Troubleshoot

Section titled “Reconnect, Disconnect and Troubleshoot”

Replace the key by reconnecting the card, and then test a report. Revoke the old key in Semrush if the platform allows. Disable cuts only use in ELChat.

  • Unable key: Copy the key from the profile and check the API access of the account. Not enough units: buy units or wait for the renewal provided for in the package.
  • No data: check the domain, regional base and presence of the domain in Semrush.
  • Different results: align base, type of report and date of collection.

Security and limitations

Section titled “Security and limitations”

Each report can consume API units. Protect the key, limit the frequency of analysis and monitor the consumption in Semrush. Figures are estimates of Semrush database, not your site’s proprietary data.

Example: SEO France follow-up

In the form, provide:

  • area:maison-atlas.example ;
  • geographical base:fr ;
  • ** API key:** a fictitious key dedicated to ELChat.

The domain without protocol identifies the target andfrselects the regional base. After validation, ask for the domain’s organic keywords and compare the selected database with Semrush. Monitor API units, as a repeat scan can be charged.
